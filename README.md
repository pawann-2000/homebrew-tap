# Pawann-2000 Tap

## How do I install these formulae?

`brew install pawann-2000/tap/<formula>`

Or `brew tap pawann-2000/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "pawann-2000/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
